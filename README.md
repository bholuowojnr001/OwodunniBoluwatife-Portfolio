# Student Portfolio and Academic Management Website

## Project Overview

This project is a responsive Student Portfolio and Academic Management Website developed as part of the COS 106 – Introduction to Web Technologies term project at Miva Open University.

The website presents the student's profile, educational background, technical skills, academic projects, and contact information. It also includes an interactive Academic Planner that allows users to organise academic tasks and monitor their progress.

The project demonstrates the practical application of HTML, CSS, and JavaScript in building a functional, responsive, and interactive website.

## Technologies Used

- **HTML5:** Used to structure the website and its content.
- **CSS3:** Used for styling, layouts, responsive design, animations, and visual presentation.
- **JavaScript:** Used to provide interactive functionality, form validation, theme switching, and academic task management.
- **GitHub:** Used for source-code storage.
- **GitHub Pages:** Used to publish the website online.

## Website Pages and Features

### 1. Homepage
Introduces the student, displays the profile photograph, provides a welcome message, and offers navigation to the other sections of the website.

### 2. About Me
Presents the student's biography, educational background, technical skills, academic achievements, career aspirations, hobbies, and multimedia content.

### 3. Projects
Displays three sample projects with descriptions, screenshots, and links to relevant sections of the portfolio.

### 4. Academic Planner
Provides an interactive task-management system. Users can:
- Add academic tasks.
- Assign subjects, due dates, and priorities.
- Mark tasks as completed or undo completion.
- Delete individual tasks.
- Filter tasks by all, active, or completed status.
- Clear completed tasks.
- View task statistics and a visual progress indicator.

Task information is saved in the browser using local storage.

### 5. Contact
Provides a contact form with name, email, phone number, and message fields. JavaScript validates the form to check for empty fields, valid email formatting, and digits-only phone numbers.

## Additional Features

- Responsive layout for different screen sizes.
- Light and dark theme switching.
- Background music through a separate music-player window.
- Educational video and audio content.
- Interactive profile photograph editing interface.
- Visual effects and hover transitions.
